# Forever Unit Frames — Plan 4: Auras (buffs and debuffs)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Buffs and debuffs on every unit frame (Player, Target, Target of Target, Pet, Focus, Party), each group configured on its own — shown, only mine, only dispellable (debuffs), time left, anchor, anchor points, offset, growth, rows, size, spacing, per row, maximum — with dispel-coloured debuff borders, stack counts, cooldown swipes, tooltips, test-mode samples, and as much as the client allows while aura data is secret.

**Architecture:** Two new files. `Elements/AuraButton.lua` draws one aura into a plain (never secure) icon frame: readable fields go straight to widgets; secret fields are either passed to widgets untouched (icon) or replaced by what the client hands out for the aura instance ID (count string, duration object for the swipe, dispel colour from a colour curve); every client call is guarded and a refusal leaves that part empty. `Elements/Auras.lua` is the element: per frame two groups (buffs, debuffs), each a plain holder frame with a pool of icons made once and reused, anchored to the frame, health bar, power bar, castbar or the other group, sized to what it shows. Reads use `C_UnitAuras.GetUnitAuras` with the client doing the filtering (`HELPFUL` / `HARMFUL`, `PLAYER`, `RAID`) and sorting; `UNIT_AURA` update info is applied incrementally (one icon, or one group) and falls back to a full read when anything in it is unreadable. The options page is pure schema (an "Auras" tab); layout maths lives in `Core/Layout.lua`.

**Tech Stack:** Lua 5.1, WoW: Forever API (Interface 16001, build 1.60.1.69977), offline tests with `lua5.1` + `tests/mock.lua` (`tests/run`).

### How Blizzard shows auras under these rules (research summary)

- **Target / focus frame auras** (`Blizzard_UnitFrame/Shared/TargetFrameAuraButton.lua`, `TargetFrameAuraContainer.lua`) are loaded `[LoadIntoEnvironment secure]` (`Blizzard_UnitFrame.toc:45, 47`): secure code that may compare and subtract secret aura fields (`auraData.duration > 0`, `CooldownFrame_Set(...)`). Addons cannot copy that.
- **The aura container system** (`Blizzard_AuraContainer`, `UseSecureEnvironment: 1`) drives its buttons from secure code too, and passes display values only: `SetCooldownFromDurationObject(auraDuration)` (`Blizzard_CustomAuraButton.lua:603`), `GetAuraDispelTypeColor(..., curve)` (`:494`), `SetText(applications)`. `CustomAuraContainerTemplate` is marked `allowUntaintedCreation` (`Blizzard_CustomAuraContainer.xml:4`), so addons may be meant to create one. Not used here: its inbound API is large, no Blizzard or ForeverUI code creates one from an addon, and it cannot be tested offline (see "Open decisions").
- **Private aura anchors** (`C_UnitAuras.AddPrivateAuraAnchor`, `Doc/UnitAuraDocumentation.lua:39`) let the client draw some auras into an addon frame; ForeverUI 0.4.15 uses them for dispellable debuffs in combat. Out of scope (open decision).
- **Nameplate and party auras** (`Blizzard_NamePlateAuras.lua`, `PartyMemberFrame.lua`) are plain Blizzard Lua; they show the event pattern (full refresh on `isFullUpdate` / missing info, per-ID lookups otherwise) and the tooltip calls used here.
- **What an addon can do:** read with `GetUnitAuras` inside `pcall`; readable fields → widgets directly; secret fields → widgets that accept secrets, or the per-ID display calls above with a readable ID; refused → keep (same unit) or hide (new unit), read again at `PLAYER_REGEN_ENABLED`. This is the design below.

## Design decisions

- **Groups and pools.** `frame.auras.buffs` / `frame.auras.debuffs` = `{ key, isDebuff, holder, buttons, count, … }`. The holder is a plain child frame of the unit frame at level + 5 (above the bars). Icons are created on first use up to the group's maximum and kept; a lower maximum hides the rest.
- **Anchors.** `FRAME` = the unit frame; `HEALTH` = health bar; `POWER` = power bar, or the health bar while the power bar is hidden; `CASTBAR` = the frame's castbar (docked or detached) while it is enabled, else the frame; `OTHER` = the other group's holder. If both groups choose `OTHER`, the debuffs hang from the frame. The holder is sized to its shown icons (one physical pixel when empty), so a group hanging from it moves with it.
- **Growth.** Primary direction Right / Left / Up / Down; rows run across it (a row direction along the primary one falls back to Down for horizontal growth, Right for vertical). Icons start in the corner they grow away from (e.g. Right + Up → bottom left).
- **Defaults.** Debuffs above the frame (their bottom left on the frame's top left, 2 px up, growing right, rows up), buffs above the debuffs. Party: debuffs to the right of each member (8 px), buffs right of the debuffs, rows down. Player buffs off (Blizzard's buff frame shows them); Target of Target auras off; party buffs "only mine". Sizes 20 (party 18, pet / ToT 16), 8 per row (6 on narrow frames), maximum 16 (party 4 buffs / 6 debuffs, pet / ToT 6).
- **Reading.** `GetUnitAuras(unit, filter, max, UnitAuraSortRule.Default)` in `pcall`; the client filters (`HELPFUL|PLAYER`, `HARMFUL|RAID`, …) and sorts, so the addon never inspects an aura to decide whether to show it. "Only dispellable" is the `RAID` filter token — trivial, so it is in.
- **Showing one aura.** Icon: `SetTexture(aura.icon)` always (secret or not). Count: readable `applications` → text if > 1; else `GetAuraApplicationDisplayCount(unit, id, 2)` → `SetText`. Swipe and time left: readable `duration` / `expirationTime` → `SetCooldown`; else `GetAuraDuration` → `SetCooldownFromDurationObject`. The countdown numbers are the cooldown's own (`SetHideCountdownNumbers(not showTime)`), so the time left needs no Lua maths either way. Debuff border: readable `dispelName` → own colour table (Magic blue, Curse purple, Disease brown, Poison green, anything else red); secret → `GetAuraDispelTypeColor` with a step colour curve over the dispel type numbers → `SetVertexColor(color:GetRGBA())`. Each client call is guarded; refused parts stay empty.
- **Incremental updates.** `UNIT_AURA` with info: updated IDs that are shown → re-read that one aura; added auras → `IsAuraFilteredOutByInstanceID` per enabled group → re-read only groups that take it; removed IDs that are shown → re-read that group; anything else is ignored. A secret flag or ID, a secret answer or a refused call → full read of both groups. No info or `isFullUpdate` → full read.
- **Refusals.** A refused read on `UNIT_AURA` keeps the last icons (their swipes keep running on the client's clock); on any other event (new target, party slot, timer) the icons go. Every shown frame reads again at `PLAYER_REGEN_ENABLED`.
- **Target of target** has no aura events; its existing 0.2 s timer refreshes auras at most every 0.5 s (`Auras.POLL_SECONDS`).
- **Tooltips** on hover (`OnEnter` / `OnLeave`, plain scripts); clicks fall through to the unit button (`SetMouseClickEnabled(false)`), so clicking an aura still targets the unit.
- **Test mode** needs no change to `Options/TestMode.lua` or `Units/Party.lua`: `Auras.Update` shows samples while `ns.TestMode.IsOn()` (the pretend party gets them through `Party.StyleButton` → `Single.UpdateAll`), filling each enabled group to its maximum (samples repeat) so growth and rows can be set up; the `TEST_MODE` event clears samples everywhere when it ends.
- **Options.** A schema-only "Auras" tab (between Text and Castbar) with a Buffs and a Debuffs section; the 9-point anchors are dropdowns (enum settings), offsets / sizes sliders with edit boxes — the existing widgets, no window code changes.

+-- Aura icons ------------------------------------------------------------------
+-- Icons grow in a primary direction and wrap into rows that run across
+-- it. Offsets are measured from the corner the icons grow away from.
+local VECTOR = { RIGHT = { 1, 0 }, LEFT = { -1, 0 }, UP = { 0, 1 }, DOWN = { 0, -1 } }
+local HORIZONTAL = { RIGHT = true, LEFT = true }
+
+-- The row direction, or the default one (down for horizontal growth,
+-- right for vertical) when it does not run across the primary direction.
+function Layout.AuraRowDirection(primary, row)
+    if HORIZONTAL[primary] then
+        if row == "UP" or row == "DOWN" then return row end
+        return "DOWN"
+    end
+    if row == "LEFT" or row == "RIGHT" then return row end
+    return "RIGHT"
+end
+
+-- Where the first icon sits: TOPLEFT for icons growing right with rows
+-- going down, and so on.
+function Layout.AuraCorner(primary, row)
+    row = Layout.AuraRowDirection(primary, row)
+    local horizontal, vertical = primary, row
+    if not HORIZONTAL[primary] then horizontal, vertical = row, primary end
+    local v = vertical == "DOWN" and "TOP" or "BOTTOM"
+    local h = horizontal == "RIGHT" and "LEFT" or "RIGHT"
+    return v .. h
+end
+
+-- Offset of icon i (1-based) from that corner; step = icon size + spacing.
+function Layout.AuraOffset(i, perRow, step, primary, row)
+    row = Layout.AuraRowDirection(primary, row)
+    local col, line = (i - 1) % perRow, math.floor((i - 1) / perRow)
+    local p, r = VECTOR[primary], VECTOR[row]
+    return (p[1] * col + r[1] * line) * step, (p[2] * col + r[2] * line) * step
+end
+
+-- Width and height of count icons laid out this way (0, 0 for none).
+function Layout.AuraExtent(count, perRow, size, spacing, primary)
+    if count <= 0 then return 0, 0 end
+    local cols = math.min(count, perRow)
+    local lines = math.ceil(count / perRow)
+    local along = cols * size + (cols - 1) * spacing
+    local across = lines * size + (lines - 1) * spacing
+    if HORIZONTAL[primary] then return along, across end
+    return across, along
+end

local _, ns = ...

-- One aura icon: a plain frame (never secure) with the icon, a border, a
-- cooldown swipe with the client's countdown numbers, and a stack count.
-- Buttons are made once per frame and reused; Elements/Auras.lua owns them.
--
-- Aura data may be secret. Fields are only handed to widgets (SetTexture,
-- SetText, SetCooldown...) or read through ns.Secrets; a field that is
-- secret and has no widget to take it is left out.
local AuraButton = {}
ns.AuraButton = AuraButton

local Config, Secrets, Pixel = ns.Config, ns.Secrets, ns.Pixel

-- Debuff borders by dispel type; everything else (no type, enrage, ...)
-- gets NONE.
AuraButton.DISPEL_COLORS = {
    Magic = { 0.2, 0.6, 1.0 },
    Curse = { 0.6, 0.0, 1.0 },
    Disease = { 0.6, 0.4, 0.0 },
    Poison = { 0.0, 0.6, 0.0 },
    NONE = { 0.8, 0.0, 0.0 },
}
-- Icons are cropped a little: their own edge art would show inside ours.
local CROP = 0.08

function AuraButton.Create(parent, isDebuff)
    local button = CreateFrame("Frame", nil, parent)
    button.isDebuff = isDebuff
    button.border = button:CreateTexture(nil, "BACKGROUND")
    button.border:SetAllPoints(button)
    button.border:SetColorTexture(1, 1, 1, 1)
    button.icon = button:CreateTexture(nil, "ARTWORK")
    button.icon:SetTexCoord(CROP, 1 - CROP, CROP, 1 - CROP)
    button.cooldown = CreateFrame("Cooldown", nil, button, "CooldownFrameTemplate")
    button.cooldown:SetAllPoints(button.icon)
    button.cooldown:SetReverse(true)
    button.cooldown:SetDrawEdge(false)
    -- The count sits on its own frame so the swipe never covers it.
    button.cover = CreateFrame("Frame", nil, button)
    button.cover:SetAllPoints(button)
    button.cover:SetFrameLevel(button.cooldown:GetFrameLevel() + 1)
    button.count = button.cover:CreateFontString(nil, "OVERLAY")
    button:EnableMouse(true)
    button:SetMouseClickEnabled(false)
    button:Hide()
    return button
end

local function paintBorder(button, c)
    button.border:SetVertexColor(c[1], c[2], c[3], 1)
end

-- Size, fonts and countdown numbers; out of combat or on plain frames
-- only, like every Style.
function AuraButton.Style(button, scope, size, showTime)
    button:SetSize(size, size)
    local inset = Pixel.Snap(1, button, 1)
    button.icon:ClearAllPoints()
    button.icon:SetPoint("TOPLEFT", button, "TOPLEFT", inset, -inset)
    button.icon:SetPoint("BOTTOMRIGHT", button, "BOTTOMRIGHT", -inset, inset)
    local font = ns.Media.Font(Config.Get(scope, "fontFace"))
    local outline = Config.Get(scope, "fontOutline")
    local fontSize = math.max(6, math.floor(size * 0.5 + 0.5))
    ns.Texts.SetFont(button.count, font, fontSize, outline)
    button.count:ClearAllPoints()
    button.count:SetPoint("BOTTOMRIGHT", button, "BOTTOMRIGHT", 0, 0)
    button.count:SetJustifyH("RIGHT")
    -- The client writes the countdown itself: a soft outline cannot follow
    -- it, so it gets the plain outline.
    local numbers = button.cooldown:GetCountdownFontString()
    if numbers then
        local flags = (outline == "SOFT" or outline == "NONE") and "OUTLINE" or outline
        numbers:SetFont(font, fontSize, flags)
    end
    button.cooldown:SetHideCountdownNumbers(not showTime)
    button.plainBorder = Config.Get(scope, "borderColor")
    if not button.isDebuff then paintBorder(button, button.plainBorder) end
end

local function forget(button)
    button.unit, button.auraID, button.filter = nil, nil, nil
end

-- Stack count from a readable number; an unreadable one shows nothing.
local function showCount(button, aura)
    local n = Secrets.Number(aura.applications)
    if n and n > 1 then
        button.count:SetText(("%d"):format(n))
    else
        button.count:SetText("")
    end
end

-- Swipe and countdown from readable times; unreadable ones clear it.
local function showDuration(button, aura)
    local duration, expires = Secrets.Number(aura.duration), Secrets.Number(aura.expirationTime)
    if duration and expires and duration > 0 then
        button.cooldown:SetCooldown(expires - duration, duration)
    else
        button.cooldown:Clear()
    end
end

local function dispelColor(name)
    if Secrets.IsSecret(name) or type(name) ~= "string" then return AuraButton.DISPEL_COLORS.NONE end
    return AuraButton.DISPEL_COLORS[name] or AuraButton.DISPEL_COLORS.NONE
end

local function showBorder(button, aura)
    if button.isDebuff then paintBorder(button, dispelColor(aura.dispelName)) end
end

local function apply(button, unit, aura, filter)
    forget(button)
    local id = aura.auraInstanceID
    if not Secrets.IsSecret(id) and type(id) == "number" then
        button.unit, button.auraID, button.filter = unit, id, filter
    end
    button.icon:SetTexture(aura.icon)
    showCount(button, aura)
    showDuration(button, aura)
    showBorder(button, aura)
    button:Show()
end

-- Shows one aura (an AuraData table). Returns false, with the button
-- hidden, when the client refused part of it.
function AuraButton.Show(button, unit, aura, filter)
    if pcall(apply, button, unit, aura, filter) then return true end
    AuraButton.Clear(button)
    return false
end

    button:Show()
end

function AuraButton.Clear(button)
    forget(button)
    button.cooldown:Clear()
    button:Hide()
end

-- Buffs and debuffs of a unit frame: two groups, each a plain holder frame
-- with a pool of icons (Elements/AuraButton.lua). The holder hangs from a
-- region of the frame (or from the other group) and is as big as the

local built = setmetatable({}, { __mode = "k" })

local function get(frame, group, suffix)
    return Config.Get(frame.key, group.key .. suffix)
end

function Auras.Build(frame)
    frame.auras = {}
    for _, key in ipairs(ORDER) do
        frame.auras[key] = { key = key, isDebuff = GROUPS[key].isDebuff, holder = CreateFrame("Frame", nil, frame),
            buttons = {}, count = 0 }
    end
    built[frame] = true
end

-- The region a group hangs from.
function Auras.AnchorRegion(frame, key)
    local scope, to = frame.key, Config.Get(frame.key, key .. "Anchor")
    if to == "HEALTH" then return frame.health end
    if to == "POWER" then
        if frame.power and frame.power:IsShown() then return frame.power end
        return frame.health
    end
    if to == "CASTBAR" then
        if frame.castbar and Config.Get(scope, "castbarEnabled") then return frame.castbar end
        return frame
    end
    if to == "OTHER" then
        -- Two groups hanging from each other: the debuffs take the frame.
        if key == "debuffs" and Config.Get(scope, "buffsAnchor") == "OTHER" then return frame end
        return frame.auras[GROUPS[key].other].holder
    end
    return frame
end

local function place(group, i)
    local button = group.buttons[i]
    button:ClearAllPoints()
    button:SetPoint(group.corner, group.holder, group.corner,
        Layout.AuraOffset(i, group.perRow, group.size + group.spacing, group.primary, group.row))
end

-- The pool grows up to the group's maximum and never shrinks.
local function acquire(frame, group, i)
    local button = group.buttons[i]
    if not button then
        button = AuraButton.Create(group.holder, group.isDebuff)
        group.buttons[i] = button
        AuraButton.Style(button, frame.key, group.size, group.showTime)
        place(group, i)
    end
    return button
end

-- As big as the shown icons; one pixel when there are none.
local function fit(group)
    local w, h = Layout.AuraExtent(group.count, group.perRow, group.size, group.spacing, group.primary)
    local one = Pixel.One()
    group.holder:SetSize(math.max(w, one), math.max(h, one))
end

local function settle(group, count)
    group.count = count
    for i = count + 1, #group.buttons do AuraButton.Clear(group.buttons[i]) end
    fit(group)
end

local function readSettings(frame, group)
    local filter = GROUPS[group.key].filter
    if get(frame, group, "OnlyMine") then filter = filter .. "|PLAYER" end
    if group.isDebuff and get(frame, group, "Dispellable") then filter = filter .. "|RAID" end
    group.filter = filter
    group.enabled = get(frame, group, "Enabled")
    group.max = get(frame, group, "Max")
    group.perRow = get(frame, group, "PerRow")
    group.size = Pixel.Snap(get(frame, group, "Size"), nil, 1)
    group.spacing = Pixel.Snap(get(frame, group, "Spacing"))
    group.primary = get(frame, group, "Growth")
    group.row = Layout.AuraRowDirection(group.primary, get(frame, group, "RowGrowth"))
    group.corner = Layout.AuraCorner(group.primary, group.row)
    group.showTime = get(frame, group, "ShowTime")
end

    for _, key in ipairs(ORDER) do
        local group = frame.auras[key]
        readSettings(frame, group)
        group.holder:SetFrameLevel(frame:GetFrameLevel() + Auras.LEVELS)
        for i, button in ipairs(group.buttons) do

            place(group, i)
        end

Two further options, not in this plan: Blizzard's private aura anchors (`AddPrivateAuraAnchor`, what ForeverUI uses for dispellable debuffs in combat) and Blizzard's addon-creatable `CustomAuraContainerTemplate` (secure-environment aura container that works in combat but has a large, unproven API). Either could be a follow-up plan if combat reads turn out to be refused.
- Sorting uses the client's `Default` rule (your auras first); other rules (expiration, name) could become a setting.
